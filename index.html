Atributos HTML

Los atributos HTML proporcionan información adicional sobre los elementos y permiten personalizar su comportamiento y apariencia. Cada elemento puede tener múltiples atributos que definen características específicas.

Algunos de los atributos más comunes incluyen:

  • id - Identificador único del elemento
  • class - Clase CSS para aplicar estilos
  • src - Fuente de recursos como imágenes o scripts
  • href - Enlace de destino para elementos anchor
  • alt - Texto alternativo para imágenes
